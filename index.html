Follow the exchange

Ready. Choose “Next step” to begin.
01 · AGREE

Public setup

They agree on a prime p and base g. Both values are visible to everyone.

02 · KEEP PRIVATE

Pick secrets

Alice chooses a; Bob chooses b. Neither sends their secret exponent.

03 · EXCHANGE

Send public values

Alice sends A = g^a mod p. Bob sends B = g^b mod p.

04 · CALCULATE

Match the keys

Alice uses B^a mod p. Bob uses A^b mod p. The results match.

Learning demo: Small values make the arithmetic visible, but they provide no real security. A real implementation needs a vetted cryptography library, safe group parameters, authentication, and a key derivation function. This exchange establishes shared key material; it does not encrypt a message by itself.
